## 📌 Overview
This project controls a robotic hand using hand gestures captured via webcam.

## ⚙️ Technologies
- Python
- OpenCV
- MediaPipe
- Arduino
- Servo Motors

## ▶️ Run
```bash
pip3 install -r requirements.txt
python3 src/main.py

## 🔌 Arduino Code
Arduino code is available in `/arduino/servo_control.ino`

It reads serial data and controls 5 servo motors based on gesture input.
